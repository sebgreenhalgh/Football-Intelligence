# Contributing

Read [AGENTS.md](AGENTS.md), [the workflow](docs/DEVELOPMENT_WORKFLOW.md) and [the change checklist](docs/CHANGE_CHECKLIST.md). Keep source, tests and compact metadata in Git; keep media, weights, human decisions and experiment outputs external.

Use synthetic fixtures and focused tests. Never alter accepted human truth or a frozen release. Historical reproduction uses an isolated tagged checkout. Changes do not authorize inference, annotation, candidate unblinding, tracking or production promotion.
